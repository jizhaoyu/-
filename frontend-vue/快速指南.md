# Vue3 前端快速指南

## 🚀 一键启动

在项目根目录运行 `启动全部服务.bat`（Windows）或 `启动全部服务.sh`（macOS/Linux），会同时拉起后端和 Vue3 前端。

## 📦 手动安装

```bash
cd frontend-vue
npm install
npm run dev
```

## 🎯 访问地址

- **前端**: http://127.0.0.1:8080
- **后端 API**: http://127.0.0.1:5000（需先启动）

## 📂 项目结构

```
src/
├── api/              API 接口层
├── components/       Vue 组件
├── stores/           Pinia 状态
├── router/           路由配置
├── views/            页面组件
├── styles/           全局样式
└── main.ts           入口文件
```

## 🔧 核心技术

- **Vue 3.4** - 渐进式框架
- **TypeScript** - 类型安全
- **Arco Design** - UI 组件库
- **Pinia** - 状态管理
- **Vite** - 构建工具
- **GSAP** - 动画库

## 📝 开发命令

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```
